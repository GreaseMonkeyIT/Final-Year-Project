The DIRECT algorithm, from first principles

These notes explain DIRECT (DIviding RECTangles), introduced by Jones, Perttunen and Stuckman in 1993 [1]. They follow the review by Jones and Martins, “The DIRECT algorithm: 25 years later” [2], sections 1 to 3.1. Part 2 (sections 13 to 24) applies the method to maximum power point tracking.

Each section states the core idea first, then the formal statement, then an analogy. The figures run a working DIRECT implementation in your browser.

Section 0 defines every symbol, and the appendix defines every technical term. Key terms are set in bold and underlined where they are defined. 1 · [2, §1, §2.1]The problem class: bound-constrained black-box global optimization

Core ideaDIRECT finds the global minimizer of an objective function that is available only through point evaluations, over a feasible region defined by lower and upper bounds on each variable.

\[ \min_{x\in\mathbb{R}^n} f(x) \quad \text{subject to} \quad \ell_k \le x_k \le u_k,\qquad k=1,\dots,n \]
where
  • \(x=(x_1,\dots,x_n)\) is the decision vector, the set of inputs that the algorithm chooses,
  • \(n\) is the number of decision variables,
  • \(f(x)\) is the objective function, a single number to be made as small as possible,
  • \(\mathbb{R}^n\) is the space of real vectors with \(n\) components,
  • \(\ell_k\) and \(u_k\) are the lower and upper bounds of variable \(x_k\). Together they define the feasible region, a box.

Min-max normalization Added by user

Because the feasible region is a box, DIRECT applies min-max normalization to each variable separately:

\[ z_k=\frac{x_k-\ell_k}{u_k-\ell_k},\qquad k=1,\dots,n \]
where
  • \(x_k\) is the original variable, in its physical units,
  • \(\ell_k\) and \(u_k\) are its lower and upper bounds,
  • \(z_k\) is the normalized variable, equal to 0 at the lower bound and 1 at the upper bound.

DIRECT searches in \(z\). Before each evaluation it maps the point back with the inverse:

\[ x_k=\ell_k+z_k\,(u_k-\ell_k) \]

The search space becomes the unit hypercube \(\Omega=[0,1]^n\).

Why “without loss of generality”. The map is an affine map (a scaling plus a shift). It is one-to-one and keeps the order of points along each axis. The normalized problem therefore has the same minimizer, mapped to \(z\), and the same minimum value \(f^*\).

Why DIRECT needs it. DIRECT compares side lengths to find the longest sides (the set \(M\) of section 5), and it ranks boxes by their size \(d_i\). Both comparisons need a common scale. A side in volts and a side in amperes cannot be compared. After normalization every side starts at length 1.

Caution. The normalization does not change the problem, but it does change the iterates. Distances are measured in normalized units, so the chosen bounds decide which sides count as long and how \(d_i\) weighs one variable against another. With a wider range for one variable, DIRECT samples a different sequence of points, although the minimizer is the same.

Four terms define the setting:

Black-box objective. The algorithm can query \(f(x)\) at any \(x\in\Omega\), but has no analytic expression and no gradient.
Expensive evaluation. Each query has a cost (a simulation run, a laboratory test, a settling time). The cost of an algorithm is therefore counted in function evaluations, not in arithmetic operations.
Multimodal objective. \(f\) has several local minimizers. A point \(\hat{x}\) is a local minimizer if \(f(\hat{x})\le f(x)\) in some neighbourhood of \(\hat{x}\). The set of starting points from which a descent method reaches \(\hat{x}\) is its basin of attraction.
Global minimizer. A point \(x^*\) with \(f(x^*)\le f(x)\) for all \(x\in\Omega\). Its value is \(f^*\).

What “expensive” refers to Added by user

“Expensive” describes each evaluation of \(f\), not DIRECT. DIRECT does not make an evaluation cheaper. It reduces the number of evaluations needed to reach a good point. Its own overhead between evaluations is small:

  • Memory. DIRECT stores one hyperrectangle per evaluation: its center, its side lengths and \(f(c_i)\). Memory therefore grows linearly with the number of evaluations \(m\).
  • Selection. Only the lowest point of each size level can lie on the hull (section 4), so the hull is built from one point per level. A plain implementation costs about \(O(m\log m)\) operations per iteration, where \(O(\cdot)\) is the usual order-of-growth notation.
  • Division. Sorting the \(w_k\) values and creating the new boxes is simple arithmetic.

For hundreds or thousands of evaluations, this overhead takes microseconds to milliseconds, which is negligible next to one expensive evaluation. It becomes noticeable only in very long runs, at about \(10^5\) evaluations or more.

Application note: MPPT

One evaluation is one converter settling period, typically milliseconds. DIRECT's arithmetic in the controller takes far less time. The real limit is memory, because the box list grows with every sample. A controller that must suit Simulink Coder therefore caps DIRECT with a fixed evaluation budget and stores the boxes in fixed-size persistent arrays.

Derivative-free optimization Added by user

Roles. The objective \(f\) maps one input vector \(x\) to one number. The optimizer, here DIRECT, chooses the inputs, reads the returned values, and searches for the \(x\) that makes \(f\) smallest. The function \(f\) itself does not return the minimum.

Derivative-free describes the optimizer, not the function. A gradient-based method, such as gradient descent or Newton's method, uses the gradient \(\nabla f\), the vector of partial derivatives \(\partial f/\partial x_k\), to choose its step. A derivative-free method uses only values of \(f\). It does without derivatives for one of three reasons:

  • The derivative is not accessible. \(f\) is a black box, such as compiled simulation code or a physical plant.
  • The derivative does not exist everywhere. \(f\) has kinks or jumps, so it is not a smooth function. The knees of a P-V curve under partial shading are an example.
  • The derivative is too costly or too noisy to estimate. The standard estimate is a forward finite difference:
\[ \frac{\partial f}{\partial x_k}\approx\frac{f(x+h\,e_k)-f(x)}{h} \]
where
  • \(\partial f/\partial x_k\) is the partial derivative of \(f\) along variable \(k\),
  • \(h\) is a small step size,
  • \(e_k\) is the unit vector along variable \(k\).

A full gradient in \(n\) variables costs \(n+1\) evaluations. A measurement noise of size \(\sigma\) in \(f\) gives an error of order \(\sigma/h\) in the estimate, so a small step amplifies the noise.

The main families of derivative-free methods are [11, 15]:

  • Direct search: Hooke-Jeeves [16], Nelder-Mead [17] and pattern search compare values at nearby trial points.
  • Model-based methods: trust-region interpolation methods and Bayesian optimization fit a surrogate model to the samples (section 4).
  • Stochastic population methods: genetic algorithms and particle swarm optimization (PSO).
  • Deterministic Lipschitzian methods: DIRECT and its variants.

Name clash. A direct search method belongs to the family in the first item of this list. DIRECT is the acronym of DIviding RECTangles. The two are unrelated.

Application note: MPPT

P&O and INC estimate the slope dP/dV or dI/dV from two consecutive measurements. They are local finite-difference methods, which is why they stop at the nearest peak. DIRECT uses no slope estimate. It decides from sampled values and box sizes only.

A local method (gradient descent, Nelder-Mead, hill climbing) converges to the minimizer of the basin in which it starts. Global optimization must decide which basin to search, and that decision is the subject of these notes.

DIRECT came from Lipschitzian global optimization [3, 4, 5], a deterministic branch-and-bound method. Its main change is that it does not need the Lipschitz constant, hence the title of [1]: “Lipschitzian optimization without the Lipschitz constant.” A later revision by Jones adds nonlinear inequality constraints and integer variables [6].

Analogy

Hyperparameter tuning of a neural network is a typical instance. Each evaluation is a full training run, the validation loss has no usable gradient with respect to the learning rate or the depth, and the loss surface has several local minima. The engineer has a fixed budget of training runs and wants the best configuration, not the nearest one.

2 · [2, §2.1 and footnote 1]What finitely many samples can certify

Core ideaIf the only assumption is that \(f\) is continuous, no deterministic algorithm can guarantee the global minimum unless its sample points eventually become dense in \(\Omega\).

The proof in [2] is by construction. Assume a deterministic algorithm A converges to the global minimum of every continuous function without dense sampling. Then for some function \(f\) there is an interval \([\tilde{x}-\delta,\ \tilde{x}+\delta]\) that A never samples.

Define \(\tilde{f}\) equal to \(f\) outside this interval, with \(\tilde{f}(\tilde{x})=f^*-1\) and linear interpolation in between. The function \(\tilde{f}\) is continuous.

Because A is deterministic and sees identical values, it produces identical iterates and misses the new minimum \(f^*-1\). This contradicts the assumption.

Figure 2. The construction of the proof. The solid and the dashed functions agree at every sample. Only the dashed function has a lower minimum, inside the unsampled interval. No algorithm can distinguish them from these data.

The consequence sets the design space for every global method. Either it accepts everywhere-dense convergence, or it assumes more structure about \(f\) so that it can bound \(f\) between samples. Section 3 introduces the classical assumption.

Analogy

This is the sampling problem of signal processing. Without a bandwidth assumption, samples of a signal say nothing about its values between the samples, because a high-frequency component can hide there. The Nyquist-Shannon theorem recovers the signal only because it assumes a bandlimit. In optimization, the Lipschitz constant of section 3 plays the role of that bandlimit.

Three clarifications of the proof Added by user

  1. The interpolation exists only on paper. The linear interpolation builds the counterexample \(\tilde{f}\). The algorithm never computes \(\tilde{f}\). A sees only its own samples, and those values are identical for \(f\) and \(\tilde{f}\).
  2. Under continuity alone, no finite sampling rate is enough. A continuous dip can be arbitrarily narrow, so any finite set of samples leaves room for a deeper minimum. This is why the requirement is “dense in the limit”, not “dense enough”.
  3. Determinism matters. The sample points of A follow from its rules, so the counterexample can place the dip where A never samples.

With a Lipschitz bound (section 3), a finite spacing becomes enough. In one dimension with samples at spacing \(\Delta\), every point lies within \(\Delta/2\) of a sample. The function can fall by at most \(K\Delta/2\) over that distance, so

\[ f_{\min}-f^*\le\frac{K\Delta}{2},\qquad\text{so the spacing }\ \Delta=\frac{2\tau}{K}\ \text{ guarantees }\ f_{\min}-f^*\le\tau \]
where
  • \(\Delta\) is the spacing between neighbouring samples,
  • \(f_{\min}\) is the best sampled value, and \(f^*\) is the global minimum,
  • \(K\) is the Lipschitz constant,
  • \(\tau\) is the tolerance, the largest acceptable error in the minimum value.

This completes the Nyquist analogy. Without a bandlimit, no sampling rate recovers a signal. With a bandlimit, the Nyquist rate is enough. In the same way, without a Lipschitz bound no spacing certifies the minimum, and with one the spacing \(2\tau/K\) is enough.

3 · [2, §2.1, Eq. 2]Lipschitz continuity and Lipschitzian branch-and-bound

Core ideaIf the rate of change of \(f\) is bounded by a known constant \(K\), one sample gives a guaranteed lower bound of \(f\) over a whole region. The search can then refine the region whose lower bound is lowest.

A function is Lipschitz continuous with constant \(K\) if

\[ |f(x)-f(x')|\le K\,\lVert x-x'\rVert\qquad\text{for all }x,x'\in\Omega \tag{2} \]
where
  • \(x\) and \(x'\) are any two points of the search space \(\Omega\),
  • \(|f(x)-f(x')|\) is the change in the objective between them,
  • \(\lVert x-x'\rVert\) is the Euclidean norm of their difference, the straight-line distance \(\sqrt{(x_1-x'_1)^2+\dots+(x_n-x'_n)^2}\),
  • \(K>0\) is the Lipschitz constant, in units of objective per unit distance.

Geometric meaning: the Lipschitz hourglass Added by user

In one dimension, take any point on the graph and draw two lines through it with slopes \(+K\) and \(-K\). They form a double cone, like an hourglass lying on its side. The whole graph stays outside the upper and lower parts of that cone. Seen from one sample, this means \(f\) can rise or fall at most \(K\) per unit distance, which is exactly the floor \(f(c)-K\,d\) that DIRECT uses. We call this picture the Lipschitz hourglass.

Stated precisely, inequality (2) confines the graph to the left and right wedges between the two lines (the sideways hourglass, or bow tie). The upper and lower wedges are forbidden. Figure 3 lets you test this.

Relation to the derivative. For a differentiable \(f\), the smallest valid \(K\) is the supremum (least upper bound) of \(|f'(x)|\) over \(\Omega\).

For example, \(\sin x\) has \(K=1\), and \(x^2\) on \([0,1]\) has \(K=2\). A Lipschitz function need not be differentiable: \(|x|\) has a kink at 0 and is Lipschitz with \(K=1\).

Continuity alone is not enough: \(\sqrt{x}\) on \([0,1]\) is continuous, but its slope is unbounded near 0, so no finite \(K\) exists.

The classes nest as bounded derivative \(\subset\) Lipschitz \(\subset\) continuous, and neither inclusion reverses.

The condition is named after the mathematician Rudolf Lipschitz. Engineers meet it in two places: the slew rate of an amplifier (see the analogy below), and the Picard-Lindelöf theorem, which guarantees a unique solution of an ordinary differential equation when its right-hand side is Lipschitz in the state.

Application note: MPPT

For a P-V curve, \(K\) is the steepest slope of \(P\) against \(V\). It occurs on the falling side of the knees, where a bypass diode turns on. \(K\) is finite but unknown in advance, because it changes with shading and temperature. That is the case DIRECT is built for.

Hyperrectangles and their size Added by user

DIRECT partitions \(\Omega\) into hyperrectangles: boxes whose sides are parallel to the coordinate axes (in one dimension, intervals). Each has its center \(c_i\) evaluated. Its size is always the center-vertex distance \(d_i\), the distance from the center to any corner, which is half the diagonal.

Why this measure. The corners are the points farthest from the sampled center. So \(d_i\) is the largest distance over which \(f\) can drift from the one value that is known. Under the speed limit \(K\), the largest drop is \(K\,d_i\), which gives the floor \(f(c_i)-K\,d_i\). A larger \(d_i\) means more unexplored room in which a lower value could hide.

\[ d_i=\tfrac{1}{2}\sqrt{s_1^2+s_2^2+\dots+s_n^2} \]
where
  • \(s_1,\dots,s_n\) are the side lengths of hyperrectangle \(i\) (after normalization),
  • in one dimension this is \(d_i=s_1/2\), half the interval length,
  • in two dimensions, for sides \(a\) and \(b\), it is \(d_i=\tfrac12\sqrt{a^2+b^2}\).

n-D background Examples in two dimensions: the unit square (\(1\times1\)) has \(d\approx0.707\). After one cut, a \(\tfrac13\times1\) box has \(d\approx0.527\). After both cuts, a \(\tfrac13\times\tfrac13\) box has \(d\approx0.236\).

In one dimension, the interval \([0,\tfrac13]\) has \(d=\tfrac16\approx0.1667\), as in the table of Figure 4. Side lengths are powers of \(\tfrac13\), so only a limited set of sizes occurs. These size levels are the vertical columns of dots in Figure 6.

The variant DIRECT-l measures distance with the infinity norm, so its \(d\) is half the longest side [2]. The original DIRECT uses the Euclidean form above.

Every point of a hyperrectangle lies within \(d_i\) of its center, so Eq. (2) gives a lower bound:

\[ f(x)\ \ge\ f(c_i)-K\,d_i\qquad\text{for every }x\text{ in hyperrectangle }i \]
where
  • \(i\) is the index of a hyperrectangle in the partition,
  • \(c_i\) is its center point, and \(f(c_i)\) is the objective value measured there,
  • \(d_i\) is its size, the center-vertex distance,
  • \(f(c_i)-K\,d_i\) is the lower bound, or floor, of the box: no point of the hyperrectangle can have a lower objective value.

The bound has two terms, and they correspond to the two goals of any global search:

  • \(f(c_i)\) is small when the center value is good. This term favours exploitation (local search).
  • \(-K\,d_i\) is large in magnitude for a large cell. This term favours exploration (global search) of unsampled volume.

The constant \(K\) is the weight between them. A larger \(K\) puts more emphasis on exploration.

Why only a few boxes can ever win Added by user

Core ideaBoxes of the same size subtract the same \(K\,d\). So within a size group, the box with the lowest center value has the lowest floor for every \(K\). The other boxes of that group are dominated: no value of \(K\) can make them win. At most one box per size can ever win.

The table of Figure 4 shows this. Its nine boxes come in three sizes, so there are only three candidates, and each wins over its own range of \(K\) (the numbers come from the table):

  • the small box at the best center wins for small \(K\) (exploitation),
  • the best middle-sized box wins for medium \(K\),
  • the largest box wins for all large \(K\) (exploration).

A switch point is the \(K\) at which two candidates have equal floors. For the two smallest sizes it is

\[ K=\frac{f(c_a)-f(c_b)}{d_a-d_b}=\frac{-0.2561-(-0.2708)}{0.0556-0.0185}\approx0.396 \]
where
  • \(a\) is the best box of the larger size and \(b\) the best box of the smaller size,
  • below this \(K\) box \(b\) has the lower floor, and above it box \(a\) has.

These switch points are the slopes of the hull edges in Figure 6. A dominance example from the same table: \([0.778,0.889]\) with \(f=-0.2500\) and \([0.556,0.667]\) with \(f=-0.2561\) have the same size, so their floors always differ by 0.0061, and the second box always wins.

Do the dominated boxes play no role? They play no role in this iteration's choice, but they matter in four ways:

  1. They are never discarded. DIRECT has no pruning step, so every box stays in the partition with its sample.
  2. They wait in a queue. Once the group winner is split, its pieces move to a smaller size, and the next best box of that size can win, for example \([0.778,0.889]\).
  3. Their samples count towards \(f_{\min}\).
  4. Keeping them is what makes DIRECT globally convergent (section 9): no region is dropped for good.

Branch-and-bound with a known \(K\) can lock a hopeless room for good (pruning, below). DIRECT has no valid \(K\), so it cannot prove that a box is hopeless. It only moves the box to the back of the queue.

From floors to an algorithm: Piyavskii-Shubert and branch-and-bound Added by user

Core ideaWith a known \(K\), every sample gives a floor. The floors together form one curve that \(f\) never goes below, and a search can concentrate where that curve is lowest.

Lower envelope. From each sample \(x_i\), draw the lower half of its hourglass: the two lines that fall with slope \(K\). Each such cone is a true statement, “\(f\) is at least this much here”, and it covers the whole axis. Where several cones cover one point, the highest one is the strongest true statement. The floor is therefore the pointwise maximum of the cones, called the lower envelope:

\[ L(x)=\max_i\big[f(x_i)-K\,|x-x_i|\big]\ \le\ f(x) \]
where
  • \(x_i\) are the sampled points, and \(f(x_i)\) their values,
  • \(f(x_i)-K|x-x_i|\) is the lower half of the hourglass of sample \(i\),
  • \(\max_i\) takes the largest of these values at each \(x\),
  • \(L(x)\) is the lower envelope, a guaranteed floor of \(f\) when \(K\) is valid.

Between two neighbouring samples, the cone falling from the left sample meets the cone falling from the right sample. There the envelope forms a downward tooth, with its tip where the two cones cross. The whole envelope looks like a saw blade turned upside down. The Piyavskii-Shubert algorithm [3, 4] samples at the tip of the deepest tooth, the point where \(f\) could be lowest, and then repeats.

The box-wise floor of DIRECT. DIRECT uses a cheaper and looser floor. Inside hyperrectangle \(i\) it uses only the cone of the box's own center, \(f(c_i)-K|x-c_i|\). This floor jumps at every box boundary, and no bound exists along the jump. DIRECT accepts the looser floor because it needs one score per box, the bottom of its V, \(f(c_i)-K\,d_i\), and the center gives that score at once. DIRECT never builds an envelope. Branch-and-bound. The general scheme behind these methods has four steps [5]:

  1. Branch: split the search space into cells.
  2. Bound: compute a floor for each cell, here \(f(c_i)-K\,d_i\).
  3. Select and refine: split the cell with the lowest floor, the cell where the best value could hide.
  4. Prune: discard for good every cell whose floor is above \(f_{\min}\). No point of such a cell can beat the best value already found. This step is called pruning.
Analogy

You search a building for its lowest point. Each room carries a sign: “nothing in here is lower than X”. You open the room with the lowest sign first. Once you have found a spot at height 3, you lock every room whose sign shows more than 3, without entering it.

Finite convergence with a certificate. With a valid \(K\), the true minimum is always trapped between two known numbers:

\[ \min_i\big[f(c_i)-K\,d_i\big]\ \le\ f^*\ \le\ f_{\min} \]
where
  • the left side is the lowest floor over all cells, a valid lower bound because \(K\) is valid,
  • \(f^*\) is the global minimum,
  • \(f_{\min}\) is the best sampled value, an upper bound on \(f^*\),
  • the difference between the outer terms is the optimality gap.

The gap is a certificate, a proven bound on the error. Each split shrinks a cell by a factor of 3 along its divided sides, so \(K\,d_i\to0\) and the floors rise towards the sampled values. Choose a tolerance \(\tau\). Once the gap is below \(\tau\), the method stops with a guarantee. With a valid \(K\), this takes a finite number of iterations [2].

What DIRECT gives up. Without a known \(K\), there are no valid floors, no gap and no certificate. This is why DIRECT stops on a budget (section 6).

Analogy

Slew rate is a Lipschitz constant in time. If an amplifier output cannot change faster than SR volts per microsecond, a sample of \(V\) at time \(t\) bounds the output within \(V\pm\text{SR}\cdot\Delta t\) for the next \(\Delta t\) microseconds. This is the hourglass of Figure 3, with time on the horizontal axis.

Added by user The analogy also maps onto the methods. Classical Lipschitz optimization is like knowing the datasheet slew rate and using it to bound the output between samples. DIRECT is like knowing that the amplifier has some slew limit, but not the figure. Instead of guessing one value, DIRECT keeps every box that would matter for some value of SR.

The limitation: K is unknown

For a black-box function, \(K\) is not available. A valid value must bound the steepest slope anywhere in \(\Omega\), so it is usually large.

For the test function of Figure 4 the estimated Lipschitz constant is about 6, set by the steep knees of the curve. Set the slider to 6 and the largest interval wins.

An overestimate makes the method spend most evaluations on exploration and converge slowly. An underestimate gives invalid bounds that can discard the cell holding \(x^*\).

Hansen, Jaumard and Lu use estimates of \(K\) that vary across the domain [7]. Sergeyev and Kvasov combine local and global estimates with a reliability parameter \(r>1\) [8]. These methods perform well, but their speed and correctness depend on the choice of \(r\) [2].

Added by user In these methods the constant differs from region to region. DIRECT assigns no box a \(K\) of its own. Every trial \(K\) applies to all boxes at once. What differs per box is the range of \(K\), from \(K_1\) to \(K_2\), over which it has the lowest floor. In the selection diagram of section 4 (Figure 6), \(K_1\) and \(K_2\) are the slopes of the hull edges on either side of the box's point.

4 · [2, §2.1, Eqs. 3-4, Figs. 6-7]Potentially optimal hyperrectangles

Core ideaDIRECT removes the need for \(K\). In each iteration it selects every hyperrectangle that would have the lowest floor for at least one value of \(K>0\), provided that floor promises a real improvement.

The idea in five plain steps

  1. Score. For a chosen \(K\), each box gets the score \(f(c_i)-K\,d_i\), its floor. A lower score means a more promising box.
  2. The ranking depends on \(K\). With a small \(K\) the size barely counts, so the box with the best center value comes first (local search). With a large \(K\) the size dominates, so the biggest box comes first (global search).
  3. \(K\) is unknown, so DIRECT ranks the boxes for every \(K\), and keeps each box that comes first at least once. Potentially optimal means exactly this: the box could be the best one to split, if \(K\) happened to have the right value.
  4. Same-size boxes compete only on their center value, so at most one box per size is in the running (dominance, section 3).
  5. A sanity filter. A winner must promise a real improvement over the best value so far, \(f_{\min}\). Otherwise it is skipped. This mostly removes tiny boxes next to the best point. The filter is \(\varepsilon\), explained below.

In the table of Figure 4, the three winners are the potentially optimal set, and DIRECT splits all three. The other six boxes can never rank first for any \(K\).

Analogy

An interview shortlist when the weighting is unknown. Each candidate has a test score (the center value) and untested potential (the size of the box). If you do not know how much to weight potential against score, you interview everyone who would rank first under some weighting. A candidate who ranks first under no weighting cannot be the best hire, so you skip them for now.

Formal definition

Let the partition contain \(m\) hyperrectangles and let \(f_{\min}\) be the best value found so far. Hyperrectangle \(j\) is potentially optimal if some \(K>0\) exists such that

\[ f(c_j)-K\,d_j\ \le\ f(c_i)-K\,d_i,\qquad i=1,\dots,m \tag{3} \] \[ f(c_j)-K\,d_j\ \le\ f_{\min}-\varepsilon\,|f_{\min}| \tag{4} \]
where
  • \(j\) is the hyperrectangle under test, and \(i\) runs over all \(m\) hyperrectangles of the partition,
  • \(m\) is the number of hyperrectangles. Each evaluation creates exactly one, so \(m\) also equals the number of evaluations,
  • \(K\) is a trial value of the Lipschitz constant, not a known one, and the same trial value applies to every box,
  • \(f_{\min}\) is the lowest objective value sampled so far,
  • \(\varepsilon\) is the desired relative accuracy, so \(\varepsilon|f_{\min}|\) is the smallest improvement that counts.

Condition (3) states that \(j\) has the lowest floor for this \(K\). Condition (4) states that this floor improves on \(f_{\min}\) by at least the fraction \(\varepsilon\). The paper suggests \(\varepsilon\) equal to the desired relative accuracy, for example \(10^{-4}\).

What ε does Added by user

\(\varepsilon\) is DIRECT's only hyperparameter. It sets the smallest improvement worth chasing, as a fraction of the best value so far. In words, condition (4) says: a box that wins for some \(K\) is split only if its floor promises a gain of at least \(\varepsilon|f_{\min}|\) over \(f_{\min}\), even under the most favourable \(K\) for that box, which is the largest \(K\) for which it wins, \(K_2\).

Worked example. In the 1-D demo, \(f_{\min}\approx-0.2964\). With \(\varepsilon=10^{-4}\), the smallest gain that counts is \(0.2964\times10^{-4}\approx0.00003\), so a box needs a floor of about \(-0.29643\) or lower. In words, gains below 0.01% are not chased.

Which boxes it removes. Mostly the tiniest boxes next to the best point. A small box at \(f_{\min}\) has a floor only a little below \(f_{\min}\), because \(K\,d\) is small, so it fails the test. Big boxes have deep floors and pass easily. That is why the dashed line in Figure 6 cuts only the left end of the hull.

Application note: MPPT

With \(f=-P\), the margin is \(\varepsilon\) times the best power found. With a best power of 3,000 W and \(\varepsilon=10^{-4}\), a box must promise at least 0.3 W more to be worth a settling period.

Do not confuse this \(\varepsilon\) with the tolerance \(\tau\) (how close \(f_{\min}\) is to \(f^*\)) or with the \(\varepsilon\) of \(\varepsilon\)-greedy exploration (glossary).

Geometric interpretation: the selection diagram

Represent each hyperrectangle as a point \((d_i,\,f(c_i))\). This plot is the selection diagram. For fixed \(K\), the points with equal floor \(f-K\,d\) lie on a line of slope \(K\). Move this line up from below the point cloud. The first point it touches has the lowest floor for that \(K\). As \(K\) runs from 0 to \(\infty\), the touched points trace the lower-right convex hull of the cloud. These points satisfy condition (3).

Condition (4) removes the smallest hull points. Anchor a line at \((0,\ f_{\min}-\varepsilon|f_{\min}|)\) and rotate it upwards until it touches a point. That point minimizes \((f_i-f_{\min}+\varepsilon|f_{\min}|)/d_i\), and hull points smaller than it are not selected. The selection procedure is therefore: find this smallest selectable point, then follow the lower-right hull upwards. The Jarvis march computes the hull efficiently [9].

Dots of one size line up in a vertical column, and only the bottom dot of a column can be touched. The dashed line is the \(\varepsilon\) filter: boxes left of the dot it touches are skipped.

Three properties follow from the diagram:

  • As \(K\to0\), the selection is the point with the lowest \(f(c_i)\), the most exploitative choice.
  • As \(K\to\infty\), the selection is the largest hyperrectangle with the best center value among the largest, the most exploratory choice.
  • Hyperrectangles of equal size form vertical columns. Only the lowest point of a column can be selected.

Each iteration therefore spans the whole range from exploitation to exploration. DIRECT has no hyperparameter that sets this balance. Its only hyperparameter, \(\varepsilon\), prevents excessive local refinement [2, §2.2].

The hull points are a subset of the non-dominated (Pareto-optimal) points of the trade-off between size and center value [2, §2.3.2]. Some non-dominated points that lie inside the hull are not selected. Several later variants of DIRECT select them as well.

Analogy

Compare the lower confidence bound (LCB) rule of bandit algorithms and Bayesian optimization. LCB selects the option with the lowest value of (mean estimate \(-\ \kappa\cdot\) uncertainty), where the mean estimate is the predicted objective value of an option, the uncertainty is the spread of that prediction, and \(\kappa\) is a user-chosen weight on uncertainty.

The floor \(f(c_i)-K\,d_i\) has the same form, with cell size as the uncertainty.

DIRECT does not choose \(\kappa\). It selects every option that is optimal for some \(\kappa\), much as an investor who does not know their own risk preference holds every portfolio on the efficient frontier.

Why the Lipschitz picture still matters Added by user

Core ideaDIRECT drops only the value of \(K\), not the Lipschitz idea. Its whole selection rule is built on the Lipschitz floor.

  • Condition (3) compares exactly the floor \(f(c_i)-K\,d_i\) of section 3.
  • DIRECT assumes that \(f\) has some finite Lipschitz constant. Only the number is unknown, like an amplifier with an unknown slew rate.
  • The convergence argument of section 9 uses the \(K\to\infty\) end of the sweep.

The guarantee. Let \(K^*\) be the true Lipschitz constant. Lipschitzian branch-and-bound with \(K^*\) would split the box with the lowest floor at \(K^*\). That box satisfies condition (3) for \(K=K^*\), so DIRECT selects it too, unless condition (4) removes it.

Condition (4) removes it only if even this lowest valid floor lies above \(f_{\min}-\varepsilon|f_{\min}|\). In that case \(f^*\) itself lies above that value, so \(f_{\min}\) is already within the relative accuracy \(\varepsilon\) of \(f^*\).

DIRECT therefore always makes the choice that a method knowing \(K^*\) would make, while that choice still matters. The price is that it also splits the winners for every other \(K\), which is the global drag of section 11.

What it loses is the certificate of section 3, the gap between the lowest valid floor and \(f_{\min}\). This is why DIRECT stops on a budget.

DIRECT builds no model of f Added by user

Core ideaIn practice DIRECT never fits a curve, never interpolates and never predicts values between samples. Each decision uses two numbers per hyperrectangle: the value at its center and its size.

The floor \(f(c_i)-K\,d_i\), taken over all \(K\), takes the place of a model. The curves in the figures of these notes come from the known test functions and are drawn for the reader. DIRECT sees only the dots. Likewise, the saw-tooth envelope of Figure 5 is a guaranteed floor, not an estimate of \(f\).

Model-based methods take the opposite approach. They fit a surrogate model to the samples and choose the next point from the model:

  • quadratic interpolation models inside a trust region, as in Powell's derivative-free methods [15],
  • radial basis function (RBF) surrogates,
  • Gaussian process regression, also called kriging, in Bayesian optimization. The model gives a predicted value between samples and an uncertainty that grows with the distance from the nearest sample. The best-known method of this type is EGO (Efficient Global Optimization) by Jones, Schonlau and Welch [14], the same Jones who introduced DIRECT.

Surrogates do not escape the result of section 2. A Gaussian process assumes a smoothness that its kernel sets, which is an assumption about \(f\) much like a Lipschitz bound. A dip narrower than that smoothness is interpolated over and missed.

Having no model gives DIRECT two advantages. There is no model to choose or to get wrong: no kernel, no smoothness level and no model order. There is also no fitting cost, while a Gaussian process fit costs of order \(N^3\) operations for \(N\) samples. The price is the weakness of [2, §2.3.3] (section 11 here): without a model, DIRECT cannot see trends such as linearity, monotonicity or a variable that has no effect.

Application note: MPPT

The controller holds only samples of duty cycle and power. Nothing reconstructs the P-V curve between them.

5 · [2, §2.1, Algorithm 1, Figs. 2-4]Division of a hyperrectangle

Core ideaEvery hyperrectangle has exactly one evaluated point, at its center. DIRECT divides a selected hyperrectangle into thirds, so that the old center stays the center of the middle part, and each division along one dimension costs only two new evaluations.

Trisection in one dimension

A bisection would place the old center on the new boundary, and its value would no longer represent a cell. Trisection keeps it at the center of the middle third and adds the centers of the two outer thirds.

How the Figure 4 partition was built Added by user

The 1-D rule has three steps: cut the selected interval into thirds, reuse the old center as the center of the middle third, and evaluate the two outer centers. Each split costs two evaluations and divides the length by 3, so lengths run \(1,\tfrac13,\tfrac19,\dots\) and sizes \(d\) run \(0.5,\ 0.1667,\ 0.0556,\ 0.0185,\dots\) Figure 7 and the table below replay the first three iterations of the 1-D demo.

In iteration 2 all three boxes have equal size, so only the best center can win (dominance). The table is computed by the same engine as the figures.

Division in n dimensions n-D background

Let \(M\) be the set of dimensions with the maximum side length, and let \(\delta\) be one third of that length. DIRECT evaluates \(c\pm\delta e_k\) for every \(k\in M\). For each dimension it records the better of the two values:

\[ w_k=\min\{\,f(c+\delta e_k),\ f(c-\delta e_k)\,\} \tag{1} \]
where
  • \(c\) is the center of the hyperrectangle being divided,
  • \(M\) is the set of its longest dimensions, and \(k\in M\) is one of them,
  • \(\delta\) is one third of the longest side length,
  • \(e_k\) is the unit vector along dimension \(k\), so \(c\pm\delta e_k\) are the two points one third of a side away from \(c\), on either side,
  • \(w_k\) is the better (lower) of the two values sampled along dimension \(k\).

The rule in four steps:

  1. Find the longest sides of the box. After normalization they start equal.
  2. Sample \(\pm\delta\) along every longest side.
  3. For each side, keep the better of its two values, \(w_k\).
  4. Cut first along the side with the smallest \(w_k\), then cut the middle piece along the next side, in ascending order of \(w_k\).

The first cut produces the largest new cells, so the best new values become centers of the largest cells. Section 4 favours large cells, so this rule biases the search towards good values. In [2] the authors report that this bias speeds up convergence without loss of the global property. Only the longest sides are divided, so all side lengths shrink and the aspect ratio stays bounded.

Figure 8. n-D background Division of the unit square, after [2, Fig. 3], with illustrative values. Here \(w_1=\min(4,8)=4\) and \(w_2=\min(7,9)=7\). Because \(w_1\lt w_2\), DIRECT divides along \(x_1\) first, so the points with values 4 and 8 become centers of the two largest cells. The middle cell is then divided along \(x_2\). Each of the five cells has its evaluated point at its center.

Analogy

Compare the bisection method for root finding. Bisection halves the interval because a root needs only a sign change at the end points. DIRECT stores information at the center of each cell, so the division that reuses the stored point is a trisection. The choice of division follows from where the data sit.

Application note: 1-D is enough for MPPT Added by user

A tracker with one converter has one decision variable, the duty cycle, so DIRECT runs in one dimension. Three things simplify.

The size \(d\) is half the interval length. The division rule has no choice to make: there is only one side, so the \(w_k\) ordering step disappears and every split is a plain trisection. The curse of dimensionality of [2, §2.3.4] does not apply.

The parts tagged n-D background remain useful for reading [2], whose test problems have two or more variables.

6 · [2, §2.1, Algorithm 2]The complete algorithm

Core ideaDIRECT alternates two operations until a budget is spent: select all potentially optimal hyperrectangles (section 4), then divide each of them (section 5).

  1. Normalize the search space to the unit hypercube. Evaluate \(f(c_1)\) at its center. Set \(f_{\min}=f(c_1)\), the evaluation counter \(m=1\) and the iteration counter \(t=0\).
  2. Identify the set \(S\) of potentially optimal hyperrectangles.
  3. For each \(j\in S\), sample and divide \(j\) with Algorithm 1. Update \(f_{\min}\) and \(m\).
  4. Set \(t=t+1\). If \(t=T\) (or \(m\) reaches the evaluation budget), stop. Otherwise go to step 2.
where
  • \(c_1\) is the center of the unit hypercube, the point \((0.5,\dots,0.5)\),
  • \(m\) counts the function evaluations, and \(t\) counts the iterations,
  • \(S\) is the set of potentially optimal hyperrectangles of the current iteration,
  • \(T\) is the maximum number of iterations set by the user.

The stopping rule is a budget. DIRECT has no test that certifies the global minimum, which is consistent with section 2. The evaluations of one iteration are independent, so they can run in parallel [2, §2.2].

9 · [2, §2.1]Convergence: everywhere-dense sampling

Core ideaIn every iteration DIRECT divides one of the largest hyperrectangles. The largest cell size therefore tends to zero, the samples become dense in \(\Omega\), and \(f_{\min}\) converges to \(f^*\) if \(f\) is continuous near \(x^*\).

The argument has three steps.

First, the largest hyperrectangle with the best center value among the largest is always potentially optimal: for \(K\) large enough it satisfies (3), and its floor \(f-K\,d\) falls below the threshold of (4).

Second, because it is divided in every iteration, and there are finitely many cells of each size, the maximum size tends to zero.

Third, for any \(x\in\Omega\) and any \(\delta>0\), DIRECT eventually samples a point within \(\delta\) of \(x\). Continuity of \(f\) at \(x^*\) then gives convergence of \(f_{\min}\) to \(f^*\).

Section 2 shows that this is the best possible guarantee for a continuous black box. Convergence to the global minimizer only, without dense sampling, needs extra knowledge about \(f\): a bound on its first or second derivatives, or a known functional form that allows lower bounds over subregions, for example through interval analysis [2].

Analogy

Mesh refinement in finite-element analysis has the same structure. Adaptive refinement concentrates elements where the error indicator is large, but a scheme that also refines the coarsest element from time to time cannot leave any region permanently unresolved.

10 · [2, §2.2]Strengths

  • Black-box. DIRECT needs only function values, with no gradients and no Lipschitz constant.
  • Global convergence for continuous functions, in the everywhere-dense sense of section 9 [1].
  • Deterministic. Repeated runs give identical iterates, so no statistics over runs are necessary.
  • Parallel. An iteration usually selects several hyperrectangles, and their evaluations are independent.
  • No exploration-exploitation hyperparameter. The balance comes from the selection over all \(K\). Genetic algorithms, by contrast, need a population size, a selection bias and a mutation rate. The only hyperparameter, \(\varepsilon\), has a direct meaning: the desired relative accuracy.

Variants of DIRECT remain competitive. In a comparison of derivative-free solvers on problems with up to 300 variables, the DIRECT variant glcCluster was among the best performers [11].

11 · [2, §2.3, §3.1]Weaknesses, with the reported evidence

Slow refinement near the solution§2.3.1

Core ideaDIRECT keeps a share of each iteration on exploration after it has found the basin of \(x^*\). This global drag slows the final digits of accuracy.

On \(f=1+x_1+x_2\) with \(\varepsilon=10^{-4}\), DIRECT reaches 1% accuracy in 90 evaluations but needs 616 for 0.01%. After 497 evaluations the selection diagram has 10 size levels with a selected point. Ties raise the count to 38 selected hyperrectangles, and only one of them contains the minimizer.

Analogy

This is \(\varepsilon\)-greedy exploration with a constant \(\varepsilon\) in reinforcement learning. A fixed fraction of actions stays exploratory forever, so the policy approaches the optimum but converges slowly at the end. Methods that decay the exploration rate correspond to DIRECT variants that reduce global search near the solution.

Over-refinement of a local minimizer§2.3.2

If DIRECT finds a sub-optimal basin early, it can refine it to excessive accuracy.

On the Shubert function with \(\varepsilon=0\), 255 of the first 415 evaluations lie near one local minimizer, in cells with center-vertex distances down to \(10^{-7}\). The cell that contains a global minimizer is large but has a poor center value, so it sits high in its column of the selection diagram.

A larger \(\varepsilon\) reduces the cost of 0.01% accuracy (table in section 4), but \(\varepsilon>0\) also slows the final refinement of \(x^*\) itself.

No exploitation of local trends§2.3.3

The selection uses only the center value and the size of each cell. It ignores linearity, monotonicity and irrelevant variables. On the Branin function DIRECT reaches 1% accuracy in 51 evaluations. With an added third variable that has no effect on \(f\), it needs 839.

Degradation in higher dimensions§2.3.4 n-D background

To isolate \(x^*\) in a cell of side \(3^{-8}\approx1.5\times10^{-4}\), DIRECT must trisect the cell 8 times in each of \(n\) dimensions, while it also divides cells for exploration. On \(1+x_1+\dots+x_5\), the original algorithm needs 14,492 evaluations for 1% accuracy.

Inflexible partition§2.3.5

DIRECT samples only cell centers. It approaches the boundary of \(\Omega\) but never samples it, so an optimum on the boundary converges slowly. It also cannot accept a user-supplied starting point or an initial design such as a Latin hypercube.

Sensitivity to additive scaling§3.1

Adding a constant \(a\) to \(f\) does not change the problem, but it changes \(|f_{\min}|\) in condition (4), and so changes the selected set [12]. When \(f_{\min}\) is close to zero, the margin \(\varepsilon|f_{\min}|\) almost vanishes and allows excessive local search [13].

Finkel and Kelley replace the right side of (4) with \(f_{\min}-\varepsilon(f_{\text{median}}-f_{\min})\) [12], where \(f_{\text{median}}\) is the median of all values sampled so far. An added constant shifts \(f_{\text{median}}\) and \(f_{\min}\) by the same amount, so their difference does not change.

With this change DIRECT gives identical iterates on \(f\) and on \(a+b\,f\) for any \(a\) and any \(b>0\), a property called strong homogeneity.

Jones and Martins list low-dimensional applications in genetics, surgery, air transport, power generation, astronomy, fuel-cell management, photovoltaic systems, hard-disk design and aircraft routing [2]. The dimension weakness of §2.3.4 does not apply. Global drag (§2.3.1) does apply, which is why DIRECT-based trackers usually stop on a small budget and hand over to a local method.

A maximum power point near a duty-cycle limit is a boundary optimum (§2.3.5). With \(f=-P\), the margin of condition (4) scales with the power level (§3.1).

The PV array also supplies the extra knowledge that section 9 names. SummaryDIRECT in four statements

  1. A known Lipschitz constant \(K\) would give each hyperrectangle the floor \(f(c_i)-K\,d_i\), which weighs exploitation against exploration.
  2. DIRECT selects every hyperrectangle that minimizes this floor for some \(K>0\): the lower-right convex hull of the \((d,f)\) diagram, cut at the small end by the \(\varepsilon\) condition.
  3. It divides each selected cell by trisection along its longest sides, reuses the center value, and gives the best new values the largest cells.
  4. Because a largest cell is divided in every iteration, the samples become dense and \(f_{\min}\to f^*\). In practice the run ends on an evaluation budget.

AppendixGlossary of terms

Terms in the order of first use.

Objective function
The function \(f\) whose value the optimization minimizes (or maximizes). Also called the cost function or fitness function.
Decision variable, decision vector
One input \(x_k\) that the algorithm can choose, and the vector \(x\) of all of them.
Feasible region
The set of inputs that satisfy all constraints. For DIRECT it is a box defined by bounds on each variable.
Bound-constrained problem
A problem whose only constraints are a lower and an upper limit on each variable.
Min-max normalization Added by user
Rescaling of a variable from its range \([\ell,u]\) to \([0,1]\) by subtracting \(\ell\) and dividing by \(u-\ell\).
Affine map Added by user
A linear scaling followed by a shift. It maps straight lines to straight lines, and with a positive scale it keeps the order of points along each axis.
Black-box function
A function that is known only through its output values at chosen inputs. Its formula and derivatives are not available.
Function evaluation
One computation or measurement of \(f\) at one input. The standard unit of cost for black-box methods.
Multimodal function
A function with more than one local minimum.
Local minimizer
A point whose objective value is not higher than that of any point in some neighbourhood around it.
Global minimizer
A point whose objective value is not higher than that of any point in the whole feasible region.
Basin of attraction
The set of starting points from which a descent method converges to a given local minimizer.
Derivative-free optimization
Optimization that uses function values only, without gradients.
Gradient Added by user
The vector of partial derivatives of \(f\). It points in the direction of steepest increase.
Smooth function Added by user
A function with continuous derivatives (to the order that the context needs). It has no kinks and no jumps.
Finite difference Added by user
An estimate of a derivative from function values at nearby points, such as \([f(x+h)-f(x)]/h\).
Direct search method Added by user
A derivative-free method that compares function values at trial points around the current point, such as Hooke-Jeeves, Nelder-Mead or pattern search. Not related to DIRECT.
Descent (local) method
A method that moves only to points with lower objective values, such as gradient descent, Nelder-Mead or hill climbing.
Deterministic algorithm
An algorithm with no random elements. The same input always gives the same sequence of points.
Dense set (everywhere dense)
A set of points that comes arbitrarily close to every point of the region. For any point and any distance \(\delta>0\), some sample lies within \(\delta\) of it.
Tolerance Added by user
The largest error the user accepts in the minimum value, written \(\tau\) in these notes.
Lipschitz continuous function
A function whose change between two points never exceeds a constant \(K\) times their distance. \(K\) is the Lipschitz constant.
Lipschitz constant, smallest Added by user
The smallest \(K\) for which inequality (2) holds. Every larger value is also a valid Lipschitz constant.
Lipschitz hourglass Added by user
The name used in these notes for the two lines of slope \(\pm K\) through a point of the graph. The graph stays in the left and right wedges between them.
Supremum (sup) Added by user
The least upper bound of a set of numbers. It equals the maximum when the maximum exists.
Euclidean norm
The ordinary straight-line length of a vector, the square root of the sum of its squared components.
Hyperrectangle
The \(n\)-dimensional form of a rectangle: a box with sides parallel to the coordinate axes. In one dimension it is an interval.
Unit hypercube
The hyperrectangle \([0,1]^n\), with all sides of length 1.
Partition
A division of the search space into non-overlapping cells that together cover it.
Center-vertex distance (box size)
The distance from the center of a hyperrectangle to any of its corners, half its diagonal. These notes call it the size \(d_i\) of the box.
Size level Added by user
The group of all boxes with the same size \(d_i\). They form one vertical column in the selection diagram.
Lower bound (floor)
A value that the objective is guaranteed not to go below over a given region.
Exploitation (local search)
Sampling near points that already have good values, to refine them.
Exploration (global search)
Sampling in large regions that have few samples, to find better basins.
Dominated box Added by user
A box with a worse center value than another box of the same size. It has a higher floor for every \(K\), so it cannot be selected in the current iteration. It stays in the partition and can win later.
Lower envelope Added by user
Here, the curve \(L(x)\) that bounds \(f\) from below, built from the Lipschitz cones of all samples.
Pointwise maximum (upper envelope) Added by user
The function that takes, at each point, the largest value of a family of functions. The lower envelope \(L(x)\) is the pointwise maximum of the cones, which other texts call the upper envelope of the cones. Both names describe the same curve.
Branch-and-bound
A search scheme that repeatedly divides the space (branch), computes a bound on each part (bound), and refines or discards parts based on these bounds.
Pruning Added by user
The branch-and-bound step that discards a cell for good because its lower bound is above the best value found.
Certificate (optimality gap) Added by user
The difference between the best value found and the lowest valid lower bound. It is a proven upper limit on the error of the best value found.
Potentially optimal hyperrectangle
A hyperrectangle that has the lowest floor for at least one \(K>0\) and whose floor improves on \(f_{\min}\) by at least \(\varepsilon|f_{\min}|\) (Eqs. 3 and 4).
Selection diagram Added by user
The plot of all boxes as points \((d_i,f(c_i))\), used to find the potentially optimal boxes (Figure 6).
Convex hull (lower-right)
The convex hull of a point set is the smallest convex polygon that contains all points. The lower-right part is the chain of its edges visible from below and from the right.
Jarvis march
An algorithm that builds a convex hull by moving from one hull point to the next, choosing the point that makes the smallest turn. Also called gift wrapping.
Non-dominated (Pareto-optimal) point
A point for which no other point is better in one criterion without being worse in another. Here the two criteria are a large size and a low center value.
Hyperparameter
A setting of an algorithm chosen by the user before the run, as opposed to a quantity the algorithm computes.
Incumbent
The best point found so far, with value \(f_{\min}\).
Surrogate model Added by user
A cheap approximation of an expensive objective, fitted to the samples and used to choose new samples.
Trust region Added by user
A neighbourhood of the current point in which a local model of \(f\) is trusted. Its size grows or shrinks with the success of each step.
Radial basis function (RBF) Added by user
A function of the distance from a center point. A weighted sum of RBFs, one per sample, gives an interpolating surrogate.
Gaussian process (kriging) Added by user
A statistical model that gives, at every point, a predicted value and an uncertainty. A kernel function sets how strongly values at two points are correlated, and so sets the assumed smoothness.
Bayesian optimization Added by user
Global optimization that fits a probabilistic surrogate, usually a Gaussian process, and samples where a rule such as expected improvement or the lower confidence bound is best.
Trisection
Division of an interval or a side into three equal parts.
Convergence
The property that the best value found approaches the global minimum as the number of iterations grows.
Interval analysis
A method that computes guaranteed bounds of a function over a box from its formula, using interval arithmetic.
Global drag
The term of [2] for the slowdown of final refinement caused by the exploratory selections that DIRECT keeps making in every iteration.
Latin hypercube
A sampling design that places one sample in each row and column of a grid in every dimension, to spread an initial set of points.
Additive and multiplicative scaling
Replacing \(f\) by \(a+b\,f\), with a constant \(a\) and a positive constant \(b\). Neither changes the location of the minimizer.
Strong homogeneity
The property that an algorithm produces the same sequence of points on \(f\) and on \(a+b\,f\) for any \(a\) and any \(b>0\).
Lower confidence bound (LCB)
A selection rule in bandit algorithms and Bayesian optimization that picks the option with the lowest predicted value minus a multiple \(\kappa\) of its uncertainty.
\(\varepsilon\)-greedy exploration
A reinforcement-learning rule that picks a random action with probability \(\varepsilon\) and the best-known action otherwise. This \(\varepsilon\) is unrelated to the \(\varepsilon\) of DIRECT.
Slew rate
The maximum rate of change of an amplifier output voltage, usually given in V/µs.
